# Elie Haddad — Personal website

A responsive personal website built with HTML and CSS. No dependencies or build step required.

## Run locally

From this directory:

```sh
python3 -m http.server 8000
```

Open the site on port 8000 in your browser. Stop the server with Ctrl+C.

## Personalize

Edit `index.html` to update the introduction, about text, project links, and contact destination. Edit `style.css` to change the colors and layout. The decorative artwork uses CSS and needs no image assets. Google Fonts are optional; the site falls back to system fonts when offline.

## Deploy

Publish the repository using GitHub Pages (Settings → Pages → Deploy from a branch → main → root), or upload `index.html` and `style.css` to any static host.
